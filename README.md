# 🤖 Repositório de Agentes (Agentic Frameworks)

Bem-vindo ao repositório de **Agentes de Inteligência Artificial**. Este projeto tem como objetivo centralizar, versionar e documentar frameworks de prompt estruturados (arquivos `AGENTS.md`) para orientar o comportamento de IAs Generativas em tarefas complexas, especialmente em Engenharia de Software.

## 🎯 Filosofia

Acreditamos que a IA é mais eficiente quando guiada por processos claros. Nossa principal bandeira é o fim do **"Vibe Coding"** (a prática de pedir para a IA gerar código de forma caótica e iterativa sem um plano arquitetural). 

Nossos agentes são desenhados com princípios de **Engenharia de Prompt Avançada**, utilizando:
- Delimitadores claros (Tags XML).
- Personas bem definidas.
- Fluxos de trabalho (Workflows) estritos.
- Loops de validação e desambiguação.

## 📂 Estrutura do Repositório

Cada agente possui sua própria pasta contendo seu arquivo de instruções (`AGENTS.md`) e sua documentação local.

```text
📦 ai-agents-repo
 ┣ 📂 mestre-jedi
 ┃ ┣ 📜 AGENTS.md      # O Core Prompt do agente Mestre Jedi
 ┃ ┗ 📜 README.md      # Instruções de uso deste agente específico
 ┗ 📜 README.md        # Esta documentação global
```

## 🚀 Como Utilizar

1. Navegue até a pasta do agente que deseja utilizar (ex: `/mestre-jedi`).
2. Leia o `README.md` local para entender o propósito do agente.
3. Copie o conteúdo do arquivo `AGENTS.md`.
4. Cole o conteúdo no campo de **System Prompt**, **Instruções Customizadas** ou **Contexto Inicial** da sua ferramenta de IA favorita.
5. Siga as diretrizes e aproveite um fluxo de trabalho altamente estruturado!
